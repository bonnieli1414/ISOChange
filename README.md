# ISO Change - PDF 電子簽章自動補蓋說明

本專案主要用於處理 ISO 變更流程中，因系統轉檔或疏漏導致 **PDF 檔案未加蓋電子簽章** 的自動化修正作業。

---

## 📂 專案結構說明

* **`06. ISO/`**：ISO 文件與簽章的存放主目錄。
  * **`文件/`**：系統說明文件及操作手冊。
  * **`電子印章/`**：系統歷次產生的電子印章備份檔（如今日與歷次簽核用圖檔）。
  * **`文管/temp/`**：暫存與各變更單對應的檔案夾。
    * **`TW-EN-26-0183-01-001/`**：本次處理的變更單檔案夾。
      * **`new/`**：包含本次待修正的 `x369cc17cx1a03e9bd4cexx36c3.pdf`（新版無簽章 PDF）與 `x369cc17cx1a03e9bd4cexx36c3.xls`（新版已蓋章 Excel 範本）。
      * **`old/`**：舊版的 PDF 與 Excel 備份。
      * **`電子印章20260828.png`**：本次指定使用、日期為 **2026.08.28** 的簽章圖檔。
* **`stamp_pdf.py`**：自動化 PDF 簽章套印 Python 腳本。

## 🛠️ 電子簽章修正邏輯與座標定位

在 Excel 中印章尺寸雖然固定為 `158.0 x 147.5 pt`，但 Excel 在將活頁簿匯出為 PDF 時，會**根據各頁面長寬比例自動縮放**（以符合 A4 紙張大小）。
為了確保 PDF 的視覺呈現與 Excel 匯出的原生列印完全一致，並**防止印章在第三頁超出紙張右側邊界**，簽章座標與縮放比例設定如下：

### 1. 第 2 頁 [加工] (對應 Excel「加工」頁籤)
* **印章來源**：`TW-EN-26-0183-01-001\電子印章20260828.png`
* **套印尺寸**：寬 `127.97 pt` / 高 `107.86 pt`（約為原始尺寸之 **81%** 縮放）
* **定位座標**：**`X = 426.70 pt`** / **`Y = 145.96 pt`**（原點位於 PDF 頁面左下角）
* **對應 Excel 儲存格**：`$I$43` 位置

### 2. 第 3 頁 [包裝] (對應 Excel「包裝」頁籤)
* **印章來源**：`TW-EN-26-0183-01-001\電子印章20260828.png`
* **套印尺寸**：寬 `145.78 pt` / 高 `122.89 pt`（約為原始尺寸之 **92%** 縮放）
* **定位座標**：**`X = 440.02 pt`** / **`Y = 146.22 pt`**（原點位於 PDF 頁面左下角）
* **對應 Excel 儲存格**：`$I$43` 位置
  *(註：此座標已根據最新 Excel 位置修正，防止了舊版 PDF 中印章偏向左側 `X = 255.82 pt` 的錯誤)*

## 💻 自動化腳本使用指南 (`stamp_pdf.py`)

本專案根目錄下附帶了 `stamp_pdf.py` 腳本，可用於後續執行補蓋簽章：

### 1. 安裝必要套件
請確保系統已安裝 Python 3，並在終端機安裝以下相依套件：
```bash
pip install pypdf reportlab pillow
```

### 2. 執行指令
預設情況下，直接執行即可自動處理本次的變更單 PDF：
```bash
python stamp_pdf.py
```

若有其他檔案需要處理，亦可透過參數指定：
```bash
python stamp_pdf.py --pdf <PDF檔案路徑> --stamp <簽章圖檔路徑> --output <輸出路徑>
```
*如果不指定 `--output`，將會直接**覆寫**原 PDF 檔案。*

## ⚠️ 常見問題排除

1. **PermissionError: [Errno 13] Permission denied**
   * **原因**：該 PDF 檔案目前已被 Acrobat Reader、Chrome 或其他軟體開啟鎖定，導致寫入失敗。
   * **解決方式**：請關閉所有開啟該 PDF 檔案的應用程式，然後重新執行腳本。
